Accessed: 2026-11-12

This compact word/POS/CEFR subset is bundled for local vocabulary classification.
CEFR-J levels are a reference indicator and do not assign a different level to each dictionary sense. The application groups dictionary senses by part of speech and displays the corresponding source level. Entries missing from the list remain unclassified.
